SEMANTIC ELEMENTS

Understanding Semantic HTML5 Elements

Semantic elements clearly describe their meaning to both the browser and the developer. Unlike generic div and span elements, semantic tags like header, nav, article, and footer tell us exactly what kind of content they contain.

Why Use Semantic Elements?

Semantic HTML improves accessibility for screen readers, helps with SEO by giving search engines better context about your content, makes your code more readable and maintainable, and provides better structure for your documents. When you use semantic elements, you're creating a more meaningful document outline that both humans and machines can understand.

Common Semantic Elements

The most commonly used semantic elements include: header (introductory content), nav (navigation links), main (dominant content), article (independent content), section (thematic grouping), aside (tangentially related content), footer (closing content), figure (self-contained content like images), and time (dates and times). Each serves a specific purpose in document structure.

Quick Tips

Remember that semantic elements are about meaning, not presentation. Don't choose an element based on how it looks by default - use CSS for styling. Choose elements based on what the content represents in your document structure.

A single page can have multiple article, section, or nav elements. Use them wherever they make semantic sense for your content organization.
