LISTS AND LINKS

Working with Lists and Links

Lists and links are fundamental building blocks of web pages. Understanding how to use them properly helps create well-structured, accessible, and user-friendly websites.

Unordered Lists

Unordered lists use the <ul> element and display items with bullets. They're perfect for lists where the order doesn't matter. Here's an example of an unordered list:

  • Apples
  • Bananas
  • Oranges
  • Grapes

Each item in the list is wrapped in an <li> (list item) tag. Unordered lists are great for navigation menus, feature lists, and collections of related items.

Ordered Lists

Ordered lists use the <ol> element and display items with numbers. Use them when the sequence matters. Here's an example of an ordered list:

  1. Preheat the oven to 350°F
  2. Mix dry ingredients in a bowl
  3. Add wet ingredients and stir
  4. Pour into baking pan
  5. Bake for 30 minutes

Ordered lists are ideal for step-by-step instructions, rankings, procedures, and any content where order is important.

Links (Anchor Tags)

Links use the <a> (anchor) element with an href attribute to create clickable connections between pages. Links are essential for navigation and connecting content. Here are some examples:

  • Link to Home Page
  • Link to Semantic Elements
  • External Link to MDN
  • Link to top of page

The href attribute specifies the destination. Use relative paths for internal pages, absolute URLs for external sites, and add target="_blank" to open links in a new tab. You can also use anchor links to jump to specific sections within a page.

List Tips

Lists can be nested inside each other to create hierarchical structures. You can also style lists with CSS to remove bullets, change numbering styles, or create horizontal navigation menus.

Always ensure links have descriptive text - avoid "click here" in favor of meaningful descriptions that tell users where the link goes.
